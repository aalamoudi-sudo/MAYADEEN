# تهيئة مركز الاستفسارات

مركز الاستفسارات يستخدم ملفي Apps Script الحاليين `Code.gs` و`Inquiries.gs`، ويحفظ البيانات في جداول مستقلة داخل ملف المشروع. لا يكتب أي سجل في WBS.

## التهيئة الآمنة

1. راجع فرق `apps-script/Code.gs` وأضف `apps-script/Inquiries.gs` إلى مشروع Apps Script نفسه.
2. من محرر Apps Script في **بيئة اختبار**، شغّل `ensureInquirySheets_` مرة واحدة. تنشئ العملية الجداول التالية وعناوينها فقط: `Inquiries` و`Inquiry Replies` و`Inquiry Events` و`Inquiry Reads` و`Inquiry Notifications`.
3. تأكد أن `User Access Matrix` يحتوي الحسابات الفعلية النشطة وصلاحيات الصفحات الصحيحة. لا تنشئ التهيئة مستخدمين أو أدوارًا.
4. اختبر بنسخة Spreadsheet معزولة، ثم أنشئ إصدار Apps Script جديد وانشره وفق عملية النشر المعتمدة. لا تغيّر `DEFAULT_API_URL` إلا بعد اعتماد الإصدار.

## ملاحظات تشغيلية

- هوية المشروع الحالية ثابتة في `INQUIRY_PROJECT_ID` وتُحفظ مع كل سجل لعزل البيانات. عند تشغيل نسخة لمشروع آخر يجب تعيين قيمة مستقلة ومراجعتها قبل النشر.
- كل عمليات الكتابة محمية بـ `LockService` وبـ `request_id` لمنع التكرار عند إعادة المحاولة.
- الواجهة تحدّث التنبيهات والعدادات كل 45 ثانية عندما تكون الصفحة ظاهرة، بصورة مستقلة عن مزامنة WBS.
- ربط المهمة متاح فقط لمن يملك صفحة المهام، ويعاد التحقق من صلاحية المرسل والمستلم في الخادم.
